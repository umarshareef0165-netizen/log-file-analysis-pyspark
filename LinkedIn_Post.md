## VERSION 1 — Achievement / Story Style (Recommended for engagement)

Just wrapped up an exciting **Big Data Analytics mini-project**: **Log File Analysis using PySpark.**

Most students stop at "count the requests, find the top IP." I took it three steps further:

- **Time-series traffic analysis** — identified peak hours when the server is under maximum load
- **Anomaly & suspicious IP detection** — flagged IPs probing `/wp-admin`, `/.env`, `/admin` — basically caught simulated attackers red-handed
- **Bot vs Human traffic classification** — used User-Agent regex matching to discover ~28% of traffic was automated

**Why this matters in the real world:**
Every production web server generates **GBs of logs daily**. Pandas would crash. PySpark scales the same code from a laptop to a multi-node cluster using lazy evaluation, the Catalyst optimizer, and distributed execution.

**Tech stack:** PySpark | Pandas | Matplotlib | Jupyter | Anaconda

**Key takeaway:** Log files aren't just "noise" — they're a goldmine for security teams, SREs, marketers, and product managers. Knowing how to mine them at scale is a superpower.
